# Qdaily Visual Style

## Core Rule

Select images by editorial function, not by source convenience.
A reliable source can still be the wrong image.

## Slot Types

- `hero`
  - Job: establish the person, event, or central tension immediately
  - Best fit: event photos, portraits in context, strong documentary frames
  - Avoid: product cutouts, homepage banners, promotional posters

- `process`
  - Job: prove how the person works or how the thing is made
  - Best fit: workshop scenes, fieldwork, meetings, backstage moments, hands-on detail
  - Avoid: generic posed portraits with no process value

- `object`
  - Job: show the product, project, space, or work being discussed
  - Best fit: clean official product images, project photography, media close-ups
  - Avoid: unrelated lifestyle images

- `achievement`
  - Job: lock in a result, milestone, or public proof point
  - Best fit: podiums, race action, celebration, award moments, verified result screens
  - Avoid: homepage banners, slogans, concept graphics

- `archive`
  - Job: add background, history, or factual context
  - Best fit: old photos, screenshots, posts, historical materials
  - Avoid: using archive material when the paragraph is really about the present

## What Makes An Image Feel Right

- It matches the paragraph it sits near.
- It looks observed, not merely branded.
- The subject is clear in under two seconds.
- It would still make sense on mobile.
- It does not need an emotional caption to become meaningful.

## Editorial Scoring Order

Use this ranking order:

1. Content match
2. Documentary or news value
3. Visual force and clarity
4. Source reliability
5. Commonness only as a weak tie-breaker

Never invert that order.

## Good Defaults For Profile Stories

- Use a strong event or person-in-context image for `hero`.
- Use `process` only when the image really shows work, not just presence.
- Use official product images for `object` when the paragraph is truly about the product.
- Use an `achievement` image only when the story reaches a real milestone.
- Leave weak slots empty.

## Captions

Captions should do one job cleanly:

- identify what is shown
- add one relevant context detail
- attribute the source when needed

Good:

- `2026 年 WSBK 赛场边的庆祝瞬间。对张雪和团队来说，这场胜利更像一次阶段性证明。`
- `500RR。对张雪机车来说，产品能不能立住，决定了这个名字最终会不会变成一个真正的品牌。`

Bad:

- `热血时刻`
- `梦想照进现实`
- `这就是热爱`

## Anti-Patterns

- Marketing posters used as hero images
- Homepage screenshots used as news photos
- A single image after every heading
- Repeating the same image or page across multiple slots
- Choosing the most common image instead of the most fitting one
- Forcing an image into a slot that should stay empty
