# Image Style

## Core Rule

Choose images by editorial function.
Do not start with the source. Start with the paragraph.

## Slot Types

- `hero`
  - establish the person, event, or central tension

- `process`
  - show work, method, making, or action

- `object`
  - show the product, project, space, or object under discussion

- `achievement`
  - prove a result, public milestone, or win

- `archive`
  - provide historical or factual background

## Ranking Order

1. content match
2. documentary or news value
3. visual clarity and force
4. source reliability
5. commonness only as a weak tie-breaker

## Good Defaults

- use event or person-in-context images for `hero`
- use official product images for `object`
- use podium, race, or result images for `achievement`
- allow `process` to stay empty if no true working-scene image exists

## Never Prefer

- homepage screenshots as article photos
- marketing banners as evidence
- decorative images with no paragraph function
- repeated use of the same image across multiple slots
